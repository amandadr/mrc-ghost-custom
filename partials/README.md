# Partials

Ghost resolves `{{> "name"}}` from this folder (nested paths allowed).

| Location | Use |
|----------|-----|
| This directory | Live layout, sections, audience, feed, icons |
| `component-library/` | Library chrome (`cl-frame-*`, `cl-nav`) |
| `legacy/` | Superseded atoms; library demos only |
| `icons/` | SVG icons via `icon` or `icons/<name>` |

Inventory: [docs/theme-map.md](../docs/theme-map.md) and [templates and partials](../docs-site/docs/architecture/templates-and-partials.md).
